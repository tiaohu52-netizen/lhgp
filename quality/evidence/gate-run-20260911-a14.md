## 4. 真命令行链路冒烟（同一隔离环境）

```
$ lhgp --data-dir <tmp> prepare --contract-id lt-20260911-a14smoke \
      --title "a14 smoke" --objective "验证候选制品能立合同" \
      --deadline 2030-01-01T00:00:00+00:00
{ "contract_id": "lt-20260911-a14smoke", "revision": 1, "state": "drafted", ... }

$ lhgp --data-dir <tmp> list          # 合同出现
$ lhgp --data-dir <tmp> approve lt-20260911-a14smoke
{ "revision": 2, ... }

$ lhgp --data-dir <tmp> get lt-20260911-a14smoke
  "revision": 2
  "state": "active"                   # drafted → active 真实落库

$ lhgp-mcp --help
usage: lhgp-mcp [-h] [--data-dir DATA_DIR]
LHGP Protocol MCP server (stdio JSON-RPC 2.0)
```

这一步同时验证了本版新增的**合同状态机在唯一写入口强制**（审计 B1）在制品里生效：
`approve` 走的就是 `drafted → active` 这条合法边，而非法边（如 `drafted → complete`）
会被拒并映射为 `STATE_FORBIDDEN`。

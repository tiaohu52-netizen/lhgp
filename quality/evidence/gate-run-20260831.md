## 首跑修复记录（门真实拦下过问题）

1. format：6 个手写文件排版不合，ruff format 自动修。
2. lint：537 个 RUF001-003 中文全角标点误伤 → 以 allowed-confusables 白名单放行
   （不改代码迎合规则，也不关规则族——保留对西里尔字母等真 confusables 的拦截）；
   1 个 N818（PrepareRefused → PrepareRefusedError）；1 个 SIM300（yoda）。
3. test：4 个信封测试失败暴露真实骨架 bug——frozen dataclass 版 RpcError
   未走 Exception 初始化导致 str(err) 为空、message 丢失；
   以 __post_init__ 显式调用 Exception.__init__ 修复。
4. coverage：首跑 65% < 70% → 补 cli/信封/词汇表三组测试后 98.14%。
